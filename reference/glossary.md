# Glossary — WashU SU finance

## Acronyms

| Term | Meaning |
|---|---|
| **SU** | Student Union |
| **FTF** | **Financial Transaction Form** — the Google form required for most transactions |
| **WUGO** | WashU's student org platform (runs on Presence). Rosters, event registration, budget submission, applications |
| **Workday** | University HR/finance system. **Expense reports for reimbursements** live here |
| **Cashnet** | The **university-approved platform for collecting funds** |
| **BAM** | **Budget Allocation Manual** — the annual budgeting guide, with funding limits |
| **BAT** | **Budget Allocation Team** — coordinators between your group and the Budget Committee |
| **BC** | Budget Committee |
| **AC / ACT** | Activities Committee / Activities Committee Team |
| **VPF** | Vice President of Finance |
| **P&T** | Presidents & Treasurers (as in "P&T emails") |
| **SAF** | **Student Activities Fee** — also the per-member travel cap figure ($682 in FY26) |
| **DUC** | **Danforth University Center** — Campus Life Suite 270 is the SU office |
| **GBM** | General Body Meeting — **not funded via appeals**; use flat funding |
| **HMC** | Harvey Media Center (equipment rental) |
| **HES** | Housekeeping/Environmental Services (cleanup fees) |
| **ACH** | Automated Clearing House — electronic bank transfer, one of the supplier payment methods |
| **W-9** | IRS taxpayer ID form; required from suppliers before payment |
| **BEARings** | **SU Finance BEARings** — the Trello board that is the official policy manual |
| **FY** | Fiscal year (FY27 = the 2026–2027 year) |

## Key systems, and what each is for

| System | Use it for |
|---|---|
| **SU Finance BEARings Trello board** | The **official policy manual**. All rules, processes, forms, dates, balances, packages. Check here first, and check it even if you found the answer in the PDF export |
| **WUGO (Presence)** | Roster upkeep, **event registration (≥14 days out)**, annual budget submission, recognition/category/name-change applications |
| **Workday** | **Reimbursement expense reports** — requires being a **student employee**. Set up email notifications |
| **Cashnet** | Collecting money from people |
| **Daily Report** | Account balances and activity, updated weekdays. Excel reports attached to the account-balance cards |

## Terms

| Term | Meaning |
|---|---|
| **Operating account** | Holds SU money (budget allocations, flat funding, appeals). **Use-it-or-lose-it**, resets at FY end |
| **Fundraising account** | Money you raise. **Carries over** |
| **Gift account** | Donations via Advancement. **Carries over** |
| **Flat funding** | Flexible annual allocation, $15/active member, Cat I & II. Usable for socials, GBMs, info sessions |
| **Budget allocation** | Annual spring award for 3 largest events + overhead. Cat I only |
| **Overhead** | Non-event operating costs; overhead allocations last all year |
| **Rolling appeal** | Mid-year funding request for something not in your budget. Cat I only |
| **Re-appeal** | Request to supplement prior funding. **Refused** unless the event was last funded in your annual budget |
| **Reallocation** | Moving already-allocated funds to a different purpose. Same-event line moves: Business Ops at spending time. Different events: FTF → VPF |
| **Canceled event retrieval** | Returning unneeded allocated funds so they can be reused for appeals |
| **Deficit spending** | Spending/committing before funding exists. **Never funded, no exceptions** |
| **Budget name** | The specific allocation an expense is pulled from. **Every FTF asks for this** |
| **Project number** | Your group's accounting identifier; needed for Workday expense reports |
| **Cost center** | Accounting unit paired with the project number |
| **Restrictions on Accounts** | The list of what may not be purchased. Two tiers: items barred from **operating** funds, and items barred from **any** funding |
| **Spending blackout period** | Windows near semester end when spending is halted |
| **Premiere spaces** | Event Management's higher-tier venues. **IT and AV charges are not covered by SU** |
| **Interest survey** | Required (≥5 days open) for speakers with honoraria over $10,000 |
| **Travel conference** | Event category "Travel (50–500 miles)" or "Travel (500+ miles)" — max 4 attendees |
| **Local conference** | Event category "Local Off-Campus" — no attendee restriction |
| **Category I / II / III** | Funding tiers. See categories.md |
| **Good standing** | Campus Life compliance status; affects whether events get approved |
